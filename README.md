# Bubble Game

A simple interactive Bubble Game built with HTML, CSS, and JavaScript.

## How to Play

1.  Click on the bubble that matches the "Hit" number.
2.  Score points for every correct hit.
3.  The game ends when the timer runs out.

## Deployment

### Deploy to Vercel

This project is ready to be deployed on Vercel.

1.  Push this repository to GitHub/GitLab/Bitbucket.
2.  Import the project into Vercel.
3.  Vercel will automatically detect it as a static site.
4.  Click **Deploy**.

No build command is required.
